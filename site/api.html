Public API

Version 1 · read-only · free

Everything public on Firstprint is also available as JSON: which tokens are coming up, every open market with its pool and outcomes, settled results, and the leaderboard. Use it for bots, dashboards, alerts or research.

  • Base URL: https://www.firstprint.fun/api/v1
  • No key, no sign-in. Only GET requests. Any website can call it from the browser (CORS is open).
  • Limit: 60 requests a minute per address, and a shared limit for everyone together. Over a limit you get 429; wait a minute and try again.
  • Private data is never returned: no emails, wallets, or who predicted what.
  • Points have no cash value. Nothing here is financial advice.

Endpoints

GET/api/v1/upcoming

Tokens that aren’t trading yet. Their opening price will be the start price. Sorted by when predictions close, soonest first.

curl https://www.firstprint.fun/api/v1/upcoming

GET/api/v1/markets?status=open&limit=50

Markets, newest activity first.

  • status: open (taking predictions, the default), closed (predictions closed, waiting for the result), settled (result posted), or all.
  • limit: 1 to 100, default 50.
curl "https://www.firstprint.fun/api/v1/markets?status=settled&limit=10"

GET/api/v1/markets/{id}

One market. Returns 404 if there is no such market.

GET/api/v1/leaderboard?period=week

Top players by profit. period is day, week, month or all. Each entry has rank, username, profit, wins and predictions.

FieldMeaning
typeyes_no (above or below the start price) or five_outcomes (price ranges).
categorylisting for a new listing, live for a token that already trades.
statusopen, closed, settled or cancelled.
upcomingtrue while the token isn’t trading yet.
startPriceThe price outcomes are measured from, or null until it’s known.
startPriceFromset (already known), opening_price (the first trading price) or price_at_close (the price when predictions close).
poolPoints predicted on this market in total.
outcomes[].sharePart of the pool on this outcome, from 0 to 1: the crowd’s view.
outcomes[].payoutWhat 1 point on this outcome would return if it won, as the pool stands now (after the fee). null when nothing is on it yet.
resultOnce settled: winningOutcome, startPrice, finalPrice, and cancelledReason if it was cancelled.

Errors

Errors come back as JSON with a short code, for example {"error": "bad_status", "message": "…"}, and a 4xx status. Answers may be cached for up to 15 seconds, so checking every 15 to 30 seconds is plenty.

Fair use

Please keep to the limit, and link back to Firstprint if you show this data publicly. Version 1 won’t change in ways that break your code; new fields may be added. Questions or ideas: team@firstprint.fun
